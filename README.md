# STERLITZ-PLAYER

Lecteur audio hi-fi vintage pour Mac.

## Télécharger

👉 **[Télécharger la dernière version](https://github.com/patchistador/sterlitz-player-download/releases/latest/download/STERLITZ-PLAYER-mac.zip)** : fichier `STERLITZ-PLAYER-mac.zip`, 123 Mo (Mac avec puce Apple M1, M2, M3…, macOS 13 ou plus récent). Ce lien donne toujours la dernière version.

## Installer

1. Double-clique le `.zip` : l'app **STERLITZ-PLAYER** apparaît.
2. Glisse-la dans **Applications**.
3. Première ouverture : macOS dit qu'il ne peut pas vérifier le développeur (l'app n'est pas signée par Apple).
   Clique **Terminé**, puis va dans **Réglages Système → Confidentialité et sécurité**, descends et clique **Ouvrir quand même**.
   C'est à faire une seule fois.
